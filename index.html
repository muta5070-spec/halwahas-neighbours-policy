Как получить виртуальный участок

В режиме проверки через браузер новые подписчики @halwahas.ru определяются по списку подписчиков Instagram. После повторного обнаружения ника в полностью загруженном списке за ним отмечается участок. Писать в Direct не нужно. Проверки зависят от доступности Instagram и работающего браузера оператора. Участок — часть виртуального квартала, а не объект недвижимости.

Какие данные используются

При проверке через браузер используются @ники из списка подписчиков @halwahas.ru, время наблюдения, служебные отметки проверок и номер участка. Рекомендации Instagram не считаются подписчиками. Пароли и файлы авторизации участников не запрашиваются. Этот способ связывает участок с наблюдаемым ником, а не с неизменяемым идентификатором аккаунта.

Для отдельного подключения через официальный API предусмотрены следующие данные:

Идентификатор аккаунта Instagram для этого приложения, @ник, результат проверки подписки, номер виртуального участка, время привязки и проверки. Для защиты от повторной выдачи сохраняются служебные идентификатор и время заявки, её статус и количество попыток обработки. Тексты сообщений Direct не сохраняются. Остальная переписка не используется для выдачи участков.

Что видно другим людям

В открытом квартале отображаются @ник, ссылка на Instagram-профиль и номер участка. Внутренний идентификатор Instagram и служебные данные заявки не публикуются. При автоматической выдаче по подписке ник нового участника и ссылка на его профиль становятся видны в открытом квартале. Порядок удаления указан ниже.

Проверка и хранение

В браузерном режиме проверяется видимый список подписчиков. Ошибка или неполная загрузка списка не удаляет участки; смена или повторное использование ника требует отдельной проверки оператором. Автоматический перенос участка другому аккаунту по совпадению ника не выполняется. В отдельном режиме проверки через API приложение обращается к официальному API Meta. Реестр участков хранится на сервере HALWAHAS с ограниченным доступом. Привязка сохраняется до запроса на удаление. Повторная заявка проходит новую проверку подписки. Отписка сама по себе не запускает автоматическое удаление участка.

Как удалить данные и привязку участка

Напишите на halwamarket@mail.ru с темой «Удаление данных Instagram — Соседи». Укажите свой @ник и, если известен, номер участка. После проверки, что запрос поступил от владельца аккаунта, оператор удалит его привязку и связанные персональные данные заявки. Для подтверждения владения может потребоваться обращение с соответствующего аккаунта Instagram. Пароль или API-ключ участника не требуются.
